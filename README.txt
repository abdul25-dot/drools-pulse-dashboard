DROOLS PULSE DASHBOARD

Contents
- Drools-Pulse-Dashboard.html: complete standalone dashboard application.

How to use
1. Extract the ZIP.
2. Open Drools-Pulse-Dashboard.html in a modern browser.
3. Upload an Excel workbook or CSV and confirm the column mappings.

Excel workbook parsing loads SheetJS from its CDN, so an internet connection is required for .xlsx/.xls files. CSV parsing works in the browser without that library. Data analysis is performed locally in the browser.
